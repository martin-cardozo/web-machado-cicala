Este repositorio contiene la arquitectura utilizada para el desarrollo y despliegue de la plataforma web oficial de **Machado Cicala** (Gabriel Machado y José Cicala), un reconocido estudio nacional e internacional de fotografía y producción audiovisual.

🔗 **Sitio en vivo:** [machadocicala.com.ar](https://www.machadocicala.com.ar)

---

## 🎯 Descripción del Proyecto

El objetivo principal de este proyecto fue diseñar e implementar una plataforma digital de impacto visual que funcione como el portafolio principal del estudio Machado Cicala. El sitio está enfocado en destacar el trabajo artístico de los fotógrafos/directores mediante galerías de alta resolución y secciones multimedia.

La plataforma está estructurada para mostrar las dos grandes vertientes del estudio:
1. **Fotografía:** Advertising, Beauty, Celebrities, Entertainment, Fashion, etc.
2. **Audiovisual (Film):** Films, Short Films, Music Videos.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** React.js*, CSS Modules / HTML5.
* **Backend:** Node.js / Express.
* **Arquitectura:** Diseño 100% Responsivo orientado a UX/UI y rendimiento (Lazy Loading, Image Optimization).

## 🚀 Características Principales

* **Galerías Optimizadas:** Implementación de carga diferida (lazy loading) y optimización de renderizado para soportar imágenes de altísima calidad sin comprometer el rendimiento.
* **Diseño Responsivo:** Experiencia de usuario fluida y adaptable desde dispositivos móviles hasta pantallas de alta resolución.
* **Estructura Modular:** Navegación clara dividida en Fotografía, Audiovisual, Servicios, Biografía y Contacto.
* **SEO Básico & Accesibilidad:** Mejora en el posicionamiento web del portafolio.

## 💼 Mi Rol en el Proyecto (Desarrollador Web Full Stack - Freelance)

Como único desarrollador encargado de este proyecto freelance, mis responsabilidades abarcaron:
- Relevamiento de requisitos directamente con el cliente (estudio fotográfico).
- Maquetación y desarrollo completo de la interfaz de usuario.
- Implementación de la lógica de enrutamiento y carga de galerías multimedia.
- Puesta en producción, asegurando tiempos de carga mínimos y disponibilidad del sitio.
